Require ``jinja2>=3.1.6`` for the documentation build, instead of pinning the
vulnerable ``jinja2==3.1.3``.

The old experiment scripts (``experiments/``) are no longer in the repository.

Publish the package to PyPI automatically when a GitHub release is published.

Tests that take several seconds and duplicate a faster test are marked ``slow`` and run only with ``--run-slow``: in CI, in the Linux coverage job and in the weekly jobs. All CI jobs print the 20 slowest tests. ``SDTrfistat`` collects the flagged channels 4 times faster (the tables were stacked row by row). The imager test setups no longer draw debug plots, halving their time (the plots are tested elsewhere).
