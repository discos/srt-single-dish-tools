``SDTimage --crosses-only`` has been removed: use the new ``SDTcross`` instead. ``SDTimage`` no longer saves cross-scan profiles.

Image ``-Sdev`` maps are now the standard deviation of the samples in each pixel normalized by N - 1 (it was N), NaN where a pixel has fewer than two samples (it was zero or, by rounding, NaN). With quick calibration (``calibrate_images``), the calibrated Sdev is the raw Sdev times the absolute value of the calibration factor (it included the calibration error).
