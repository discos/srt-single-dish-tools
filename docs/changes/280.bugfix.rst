SDTcal no longer stops when the Gaussian fit of a single subscan raises an error (e.g. on a strong spike): the subscan is skipped with a warning.

In the ``<channel>_cal`` columns that ``ScanSet.calculate_avg_cross`` writes (saved in the dump file), flagged samples are now NaN instead of zero.

Interactive filter: each key press is processed once (it was processed twice, so a zap interval had zero width); zap intervals work whichever border is selected first; the zap and baseline markers stay visible after an update; closing the window with the mouse no longer hangs; matplotlib's own shortcuts on the same keys (e.g. ``r``, ``q``) are disabled while the window is open; the key handlers are no longer lost with non-blocking backends; with a non-interactive backend, the filter returns with a warning.

Interactive filter, saving the results: a new zap interval adds to the existing flags instead of replacing them (also the RFI and spike flags); unflagging a scan (``v``) removes the old flags but keeps the zap intervals of the same session; a zero baseline is no longer subtracted (and the scan is no longer marked as baseline-subtracted); ``Scan.interactive_filter`` no longer raises a ``KeyError`` when the window is closed without changes.

srttools no longer forces the matplotlib backend (it used TkAgg whenever DISPLAY was set, Agg otherwise): the backend chosen by the user (``MPLBACKEND``, ``matplotlibrc``) or the platform default is used, e.g. the native macOS one.

Plots that are only saved to files (debug plots, calibration summaries, ``SDTcross`` profiles, RFI statistics, ...) are now drawn on figures not attached to pyplot: they never open a window with interactive backends and no longer pop up when the interactive filter opens. Some were also left open (RFI statistics, destriping) or saved before adding the legend (outlier removal).

The alt-az diagnostic plots (``delta_altaz.png``, ``altaz_with_src.png``) are written to the current directory only in debug mode.

Quick calibration of images (``calibrate_images``) no longer gives a flux of exactly one calibration factor to pixels with NaN Sdev; the Sdev is calculated around the pixel mean, so it is never NaN by rounding and keeps its precision with large offsets.
